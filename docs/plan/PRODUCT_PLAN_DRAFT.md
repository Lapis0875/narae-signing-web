# 온라인 서명 보드

---

## 필요한 기능

1. macOS등 노트북 환경에서 서명 보드를 디자인할 수 있음. 이 작업을 하는 사람을 '관리자'라고 칭함. 하나의 서명 보드에 대해 관리자는 1명만 존재함.
  1. 관리자는 서명 보드를 편집하는 화면을 먼저 보게 됨.
    1. 서명 보드의 배경화면은 이미지를 넣을 수 있어야 함.
    2. 서명 칸은 기본적으로 이름 없이 서명만 표시해야 함.
    3. 서명 칸의 배경색도 흰색 / 투명 중에 설정 가능해야 함.
    
      (서류 형식의 이미지 + 이름 옆에 서명 칸이 있는 디자인)
    4. 서명 칸은 마우스로 이동 및 크기 조정이 편리하게 가능해야 함.
  2. 서명 보드의 설정이 완료되면, 별도의 탭에서 실시간으로 제출된 서명을 볼 수 있는 화면이 나타나야 함. 이 화면은 전체보기로 서명 보드만 보는 용도임.
    1. 이때, 서명 보드에 표시되는 서명 칸은 기본적으로 서명자의 이름과 서명의 배경색을 표시하지 않음.
    2. 앞서 서명 보드의 편집 화면에서 배치한대로 서명 보기 화면에서 표시되어야 해.
2. iPad 등 태블릿 환경에서 공유 링크로 접속 후 서명을 펜으로 작성 및 제출할 수 있음. 서명을 하는 사람은 '서명자'라고 칭하며, 하나의 서명 보드에 여러명 존재할 수 있음.
  1. 이때, macOS에서 생성한 서명 보드에 대한 공유 링크로 접속하면 서명 화면이 있는 웹페이지가 열림
  2. 먼저 서명자 이름(서명 칸을 구분하기 위한 고유값)을 입력 후 다음 페이지로 넘어감
  3. 다음 페이지에서는 흰 칸 안에 서명할 수 있는 간단한 화면이 주어짐.
  4. 서명은 펜으로 진행되므로, 웹페이지가 펜 입력을 처리할 수 있어야 함.
  5. 서명이 완료되면, 제출 버튼을 눌러 서버에 서명을 전송함.
  6. 서명 이미지는 기본적으로 펜으로 그린 부분만 저장함. (배경 X, 투명하게)
3. 서버에 편리하게 배포할 수 있어야 함.
