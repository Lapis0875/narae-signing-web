# 온라인 서명 보드 제품 기획서

## 1. 문서 목적

이 문서는 행사 현장에서 참여자의 손글씨 서명을 수집하고 실시간으로 전시하는 온라인 서명 보드의 기능 기획을 정의한다. 구현 방식, 인프라, 배포 절차는 다루지 않는다.

## 2. 제품 정의와 범위

- 제품 성격: 법적 효력을 목적으로 하지 않는 행사 참여용 서명 보드
- 보드 단위: 행사 하나당 보드 하나, 배경 이미지 하나, 캔버스 하나
- 규모: 보드당 최대 50명의 사전 배정 서명자
- 서비스 언어: 한국어
- 지원 환경
  - 관리자: macOS를 포함한 데스크톱 브라우저
  - 서명자: iPad 및 Android 태블릿 브라우저
  - 입력: 펜·스타일러스와 손가락 터치
  - 제외: 스마트폰 서명

## 3. 역할과 권한

| 역할 | 권한과 책임 |
| --- | --- |
| 관리자 | 운영자가 사전에 생성한 계정으로 로그인한다. 여러 보드를 생성·편집·운영·삭제할 수 있다. 각 보드의 관리자는 한 명뿐이다. |
| 서명자 | 계정 없이 행사 공유 링크 또는 QR 코드로 접속해, 자신에게 배정된 칸에만 서명한다. |

관리자 계정은 공개 가입을 제공하지 않는다. 운영자가 계정을 사전에 생성하고, 관리자는 이메일·비밀번호로 로그인한다. 비밀번호 재설정은 이메일 기능 없이 운영자가 수동으로 처리한다. 이메일 인증, 이메일 비밀번호 재설정, 보드 소유권 이전, 복수 관리자 기능은 범위에 포함하지 않는다.

## 4. 보드 생명주기

| 상태 | 관리자 동작 | 서명 링크 동작 | 결과물 |
| --- | --- | --- | --- |
| 설정 중 | 제목, 배경, 명단, 서명 칸을 준비·수정한다. | 대기 안내를 표시하고 서명을 막는다. | 없음 |
| 서명 진행 | 관리자가 수동으로 시작한다. 레이아웃과 명단을 계속 관리할 수 있다. | 서명자 정보 확인과 서명 제출을 허용한다. | 관리자 전체보기에 실시간 반영 |
| 마감/보관 | 관리자가 수동으로 마감한다. 필요하면 다시 열 수 있다. | 종료 안내를 표시하고 서명을 막는다. | 최종 PNG 다운로드 가능 |
| 삭제 | 관리자가 확인 후 삭제한다. | 기존 링크와 QR 코드를 포함해 접근 불가 | 보드·배경·명단·서명 영구 삭제 |

### 4.1 서명 시작 조건

관리자는 다음 조건을 모두 만족할 때만 서명을 시작할 수 있다.

- 보드 제목이 입력되어 있다.
- 최소 한 개의 서명 칸이 캔버스에 배치되어 있다.
- 명단에 등록된 모든 사람이 서명 칸 하나에 배정되어 있다.

배경 이미지는 선택 사항이다. 배경이 없는 보드는 기본 16:9 캔버스로 시작할 수 있다.

### 4.2 되돌릴 수 있는 상태 변경

- 마감한 보드는 관리자가 다시 열 수 있다. 다시 열어도 같은 공유 링크를 사용한다.
- 공유 링크는 관리자가 재발급할 수 있다. 재발급 즉시 이전 링크와 기존 QR 코드는 사용할 수 없다.
- 공유 링크 재발급 시 이전 링크에서 진행 중이던 서명자 세션도 즉시 무효화한다.
- 제출된 서명 칸 삭제, 공유 링크 재발급, 캔버스 비율 변경, 보드 삭제는 영향과 결과를 설명하는 확인 단계를 거친다.

## 5. 관리자 기능

### 5.1 보드 목록과 생성

관리자는 자신의 보드를 목록에서 상태와 제목으로 구분해 관리한다. 새 보드에는 제목을 입력하고 배경, 명단, 서명 칸을 준비한다. 제목은 관리자 화면과 서명 시작 화면에 표시하며, 전체보기와 최종 PNG에는 별도 UI 텍스트로 표시하지 않는다.

### 5.2 배경과 캔버스

- 보드는 PNG 또는 JPG 배경 이미지 한 장을 사용할 수 있다.
- 배경이 있는 경우, 업로드한 이미지의 원본 비율과 해상도가 보드 결과물의 기준이 된다.
- 배경이 없는 경우, 1920×1080의 기본 16:9 캔버스를 사용한다.
- 일반적인 배경 교체는 기존 캔버스 비율을 유지한 채 새 이미지 전체를 비율 유지로 표시하고, 남는 영역은 흰색으로 둔다.
- 관리자가 새 이미지 비율로 캔버스 맞추기를 명시적으로 실행하면, 확인 후 모든 서명 칸과 제출된 서명을 새 캔버스의 상대 위치와 크기에 맞춰 함께 조정한다.
- 텍스트, 도형, 스티커, 템플릿, 다중 페이지, PDF 배경은 제공하지 않는다.

### 5.3 사전 명단 관리

각 명단 행은 아래 정보로 구성한다.

| 항목 | 필수 여부 | 규칙 |
| --- | --- | --- |
| 소속사 | 선택 | 공란을 허용한다. |
| 직책 | 선택 | 공란을 허용한다. |
| 이름 | 필수 | 공란을 허용하지 않는다. |

- 소속사·직책·이름의 조합은 보드 안에서 중복될 수 없다.
- 보드 안의 명단은 최대 50명까지 등록할 수 있다.
- 서명자 식별은 공백과 대소문자까지 포함한 정확한 문자열 일치를 사용한다. 선택 항목이 공란인 경우에도 공란 상태가 일치해야 한다.
- 관리자는 한 사람씩 직접 추가하거나, 스프레드시트 표를 붙여 넣거나, CSV/XLSX 파일을 가져올 수 있다.
- CSV/XLSX 파일은 첫 시트의 첫 행에 소속사, 직책, 이름 순서의 정확한 헤더가 있어야 한다. CSV는 UTF-8·쉼표 구분만 허용하고, 추가 열·다른 시트는 허용하지 않는다.
- 대량 입력에서 이름 누락·중복 등 오류가 있으면 오류 행을 보여 주고, 관리자가 고친 뒤 전체 명단을 다시 반영한다. 정상 행만 부분 반영하지 않는다.
- 대량 명단 교체는 서명 시작 전에만 가능하다. 서명 진행 중에는 새 참가자를 한 명씩만 추가할 수 있다.

### 5.4 서명 칸 배정과 레이아웃

- 명단의 각 사람에게 서명 칸 레코드를 하나씩 만든다.
- 새 칸은 캔버스에 자동 배치하지 않고 미배치 목록에 둔다. 관리자가 목록에서 사람을 선택해 원하는 위치에 직접 배치한다.
- 한 사람은 한 칸에만 배정된다.
- 관리자는 칸의 위치와 크기를 마우스로 조정할 수 있다. 칸끼리 겹치는 배치는 허용하지 않는다.
- 칸 배경은 기본 투명이며, 관리자가 칸별로 흰색 또는 투명을 선택한다.
- 관리자 편집 화면과 운영 목록에서는 배정된 사람의 정보를 확인할 수 있다. 전체보기와 결과 이미지에는 사람 이름과 관리용 선택 표시를 노출하지 않는다.
- 서명 진행 중에도 배경, 칸 위치, 칸 크기를 수정할 수 있다. 이미 제출된 서명은 연결된 칸과 함께 이동하고 크기가 조정된다.

### 5.5 서명과 명단의 운영 처리

- 관리자는 명단별 미제출/제출 완료/미배정 상태를 목록에서 확인하고, 해당 칸으로 이동할 수 있다.
- 초기화는 서명 이미지만 지우고 배정된 사람과 칸의 위치·설정은 유지한다. 초기화된 사람은 다시 서명할 수 있다.
- 칸 삭제는 현재 서명을 지우고 그 사람을 미배정 상태로 만든다. 미배정 사람은 칸을 다시 배치하기 전까지 서명할 수 없다.
- 미제출 사람은 명단에서 언제든 제거할 수 있다.
- 제출 완료 사람은 먼저 서명을 초기화한 뒤에만 명단에서 제거하거나 소속사·직책·이름을 수정할 수 있다.
- 행사 중 늦게 참여하는 사람은 관리자가 사람 정보와 서명 칸을 함께 추가한 뒤에만 서명할 수 있다. 누구나 사용할 수 있는 미배정 빈 칸은 제공하지 않는다.

### 5.6 공유와 전체보기

- 보드별로 추측하기 어려운 비공개 공유 링크를 제공한다. 이 링크는 검색이나 공개 목록에 노출하지 않는다.
- 관리자는 링크 복사와 QR 코드 표시를 사용할 수 있다.
- 전체보기는 로그인한 관리자만 별도 탭에서 열 수 있다. 전체보기는 보드만 전체 화면으로 보여 주며 편집·운영 제어는 제공하지 않는다.
- 전체보기는 새 서명 제출, 초기화·삭제, 칸 이동·크기 변경, 배경 변경을 즉시 반영한다.
- 서명자가 펜으로 작성 중인 획은 전체보기에 표시하지 않고, 제출에 성공한 완성 서명만 표시한다.

## 6. 서명자 기능

### 6.1 접속과 식별

서명자는 계정 없이 공유 링크 또는 QR 코드로 접속한다.

1. 보드가 서명 진행 상태이면, 제목이 보이는 시작 화면에서 소속사·직책·이름을 입력한다.
2. 입력값이 사전 명단의 정확히 한 사람과 일치하고 그 사람이 배정·미제출 상태이면 서명 화면으로 이동한다.
3. 정보가 일치하지 않으면 명단 내용이나 다른 참가자 정보를 드러내지 않는 일반 안내를 표시한다.
4. 이미 제출한 사람이 다시 접속하면 이미 서명했다는 안내를 표시하고 재서명을 막는다.
5. 보드가 설정 중이거나 마감 상태이면 각각 대기 또는 종료 안내만 표시한다.

### 6.2 서명 작성과 제출

- 서명 화면은 흰색 서명 영역을 제공한다.
- 서명자는 펜·스타일러스 또는 터치로 서명한다.
- 제공하는 조작은 전체 지우기와 제출이다. 획 단위 되돌리기, 색상 선택, 펜 굵기 선택은 제공하지 않는다.
- 서명자는 작성 화면에서 수정한 뒤 곧바로 제출한다. 별도 미리보기나 추가 확정 단계는 없다.
- 저장되는 서명 이미지는 펜 획만 포함하고 배경은 투명하다.
- 제출은 먼저 성공한 한 건만 인정한다. 동일인이 다시 접속하거나 예외적으로 동시에 제출해도 추가 서명은 허용하지 않는다.
- 네트워크 오류 등으로 전송에 실패하면 작성한 서명을 유지한 채 같은 화면에서 다시 제출할 수 있다.
- 제출이 성공하면 서명자에게 간단한 완료 안내만 표시한다. 전체보기나 다른 참가자 정보로 이동시키지 않는다.

### 6.3 정보 보관 안내

서명자가 제출하기 전에 다음 취지의 짧은 안내를 보여 준다.

> 입력한 정보와 서명은 이 행사 보드에 저장되며, 관리자가 보드를 삭제할 때까지 보관됩니다.

## 7. 전체보기와 결과물

### 7.1 전체보기 표시 규칙

- 편집 화면의 칸 배치와 제출된 서명을 같은 위치에 표시한다.
- 사람의 소속사·직책·이름, 편집용 테두리, 선택 표시, 운영 목록은 표시하지 않는다.
- 투명 칸은 배경 이미지 위에 서명 획만 표시한다.
- 관리자가 흰색으로 설정한 칸은 흰색 배경과 서명을 함께 표시한다.

### 7.2 최종 PNG

- 보드가 마감 상태일 때만 다운로드할 수 있다.
- 최종 배경과 현재 배치된 서명만 합성한 PNG 한 장을 제공한다.
- 배경 이미지가 있으면 원본 해상도와 비율을 유지한다. 배경이 없으면 1920×1080으로 출력한다.
- 명단, 서명자 이름, 편집 테두리, 선택 상태, 운영 UI는 PNG에 포함하지 않는다.
- 명단 파일 내보내기, 개별 서명 이미지 다운로드, JPG 다운로드는 제공하지 않는다.

## 8. 데이터와 접근 제한

- 보드, 배경, 명단, 서명 데이터는 관리자가 보드를 삭제할 때까지 보관한다.
- 자동 삭제, 복구 보관함, 공개 전체보기, 공개 명단은 제공하지 않는다.
- 보드 삭제는 확인 후 영구적으로 처리하며, 관련 공유 링크와 QR 코드도 무효화한다.
- 이 제품은 법적 전자서명, 본인 인증, 감사 이력, 서명 증명서 기능을 제공하지 않는다.

## 9. 명시적 제외 범위

- 법적 계약·동의용 전자서명
- 공개 관리자 가입, 이메일 인증, 이메일 비밀번호 재설정
- 여러 관리자, 보드 소유권 이전, 외부 초대 권한
- 자동 시작·자동 마감 일정
- 공개 전체보기 링크 및 참가자 간 정보 열람
- 스마트폰 서명
- 다국어 UI
- 배경 외 텍스트·도형 편집, 템플릿, 다중 페이지, PDF 배경
- 미배정 빈 칸을 통한 익명 또는 현장 자유 서명
- 명단/개별 서명의 별도 다운로드
- 인프라, 서버 배포, 운영 자동화의 구현 계획

## 10. 핵심 사용자 시나리오

### 시나리오 A: 행사 준비와 시작

1. 관리자가 로그인해 새 보드를 만들고 제목과 배경을 설정한다.
2. 명단을 직접 추가하거나 CSV/XLSX·표 붙여 넣기로 가져온다.
3. 관리자가 미배치 목록의 사람을 문서 배경 위 원하는 위치에 하나씩 배치한다.
4. 모든 사람이 배정되고 최소 한 칸이 배치되면 공유 링크와 QR 코드를 행사 참가자에게 전달한다.
5. 관리자가 서명 시작을 누르면 링크가 서명 화면으로 전환된다.

### 시나리오 B: 현장 서명

1. 참가자가 태블릿에서 링크 또는 QR 코드로 접속한다.
2. 소속사·직책·이름을 정확히 입력한다.
3. 흰 서명 영역에 서명하고 필요하면 전체 지우기로 다시 작성한다.
4. 제출 성공 후 완료 안내를 확인한다.
5. 서명은 관리자 전체보기와 보드 편집 화면에 완성 상태로 반영된다.

### 시나리오 C: 행사 중 보정과 마감

1. 관리자는 전체보기와 운영 목록으로 제출 현황을 확인한다.
2. 필요하면 칸·배경을 조정하거나 특정 서명을 초기화한다. 제출된 칸을 삭제할 경우 확인 후 미배정 상태로 전환된다.
3. 행사가 끝나면 관리자가 마감한다.
4. 관리자는 최종 PNG를 내려받고, 보드는 보관하거나 필요 시 다시 열거나 영구 삭제한다.
